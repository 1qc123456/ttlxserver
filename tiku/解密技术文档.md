## 3. 加密体系完整解析（核心结论）

### 3.1 数据库题目加密是"双层 RC2"，不是 AES！

早期误判为"RC2 外层 + AES-CBC 内层"（内层前 32 字节恒定 `5D20675C...240E1E2E...`，16 字节对齐），并为此投入大量 AES 逆向（穷举 aesKey、反推 IV 等**全部失败**）。真相：

- `EncryptHelper.DecryptQuestion(cipher)` 内部 = `RC2Decrypt(RC2Decrypt(cipher, "ttlx.@pd"), Global.CurrentGPCodeUse)`。
- 第一层 `ttlx.@pd` 解出 876 字符 Base64（内层密文 656 字节，8 字节对齐 = RC2 块）。
- 第二层密钥 = `Global.Instance.CurrentGPCodeUse`（**登录时初始化**，本环境=`0266650084`，形如"学校代码+数字"）。
- 独立进程（未登录）时 `CurrentGPCodeUse=""`，第二层 `RC2Decrypt(x, "")` **原样返回 x**，所以未登录时 `DecryptQuestion` 只体现一层（曾据此误判为单层 RC2）。
- `RC2Decrypt(string, string)` 的输入输出都是 **Base64 字符串**（内部：FromBase64 → RC2 解密 → ToBase64）。

### 3.2 密钥为什么"只在教师端运行时才有"

- 内层密钥不是静态写死，而是 `Global` 单例的属性 `CurrentGPCodeUse`，**登录成功后由教师端主程序赋值**（登录响应/本地初始化）。
- 独立加载 `TTLX.Common.dll` 反射调用时该值为空 → 一切"离线解密"路径（穷举、内存扫描、反射调用）都拿不到第二层。
- `DecryptQuestion` 的磁盘 IL 被 ConfuserEx 常量加密（40/42 字节占位/垃圾），但**预加载教师端目录全部 DLL 后**，ConfuserEx 解密器 patch 内存 IL → `GetMethodBody().GetILAsByteArray()` 可读到真实 IL（`D:\ttlxserver\inspect6.txt` 是全量反汇编）。

### 3.3 解题关键路径（可直接复现）

**方案 A（全量解密，推荐）**：宿主启动器 `tlaunch.exe`（在教师端目录，winexe，C#5 编译）：
1. `AppDomain.CurrentDomain.ExecuteAssembly("TTLXExamSystemTeacher.exe")` 在宿主进程内启动教师端。
2. 后台线程（`Launch2.cs`）轮询 `Global.CurrentGPCodeUse` 直到非空且 `DecryptQuestion(测试密文)` 输出以 `----` 开头（明文特征，32 个 `-`）。
3. 就绪后遍历 `TimuDetail` 全部 `TimuDesc`，`plain = DecryptQuestion(cipher)` 直接输出明文，写 `operate_decrypted.jsonl`。
4. **注意**：登录后教师端会经 `TTLXAutoUpdate.exe` 重启为独立进程，宿主进程内 `ExecuteAssembly` 返回；此时 `Global` 静态值仍在宿主进程内，宿主 Main 需 `Sleep` 保持存活等待 Worker 完成。
5. 自动登录用 WScript.Shell `AppActivate(pid)` + `SendKeys("tc07{TAB}123456{ENTER}")`。

**方案 B（客观题，已完成）**：走学生端 HTTP API：
- `POST /api/exercise/zizhu`（响应=`<hex长度>\r\n`+gzip(AES-ECB(JSON))，传输 key=`ttlx.@xl.0811.zy`），按 (specialtyid,course) 抽题去重得 42,803 道。
- 注意：学生端练习池服务端写死，无法拿到全部（单选 62%、多选 0、判断部分）。如需补全需走教师端 SQL 解密（`Questionsinfo_New.Name` 用与操作题相同的双层 RC2 体系）。

## 5. 逆向过程的关键经验（踩坑记录）

1. **32 位进程**：教师端 DLL 是 x86，反射/ClrMD 必须用 32 位 PowerShell（`C:\Windows\SysWOW64\WindowsPowerShell\v1.0\powershell.exe`）和 32 位 csc（`C:\Windows\Microsoft.NET\Framework\v4.0.30319\csc.exe`），否则 BadImageFormatException。
2. **C#5 编译器限制**：无 `?.`、无模式匹配、无局部函数、`GetMethod(name,flags,types)` 三参重载会调错（用自写 Find 按参数匹配）。
3. **ConfuserEx**：`[ConfusedBy]` 特性、方法体 IL 磁盘垃圾（JIT 解密）、常量加密（字符串藏零宽命名字段）、主 exe 反篡改（独立 LoadFrom+GetTypes 进程静默终止）、**防 OpenProcess（反调试）**——ClrMD 附加一律 error 5，提权也不行；但**宿主 ExecuteAssembly 在同一进程内运行**可完全绕开。
4. **预加载全部 DLL 触发解密器**：`foreach dll in dir: Assembly.LoadFrom(dll)` 后，`GetMethodBody().GetILAsByteArray()` 返回解密后的真实 IL（`inspect6.txt`）。
5. **RC2 输出是 Base64**：程序 `RC2Decrypt(string,string)` 输入输出都是 Base64 字符串，别自己按字节解。
6. **混淆 IL 反汇编**：跳转被 `br.s` 打乱，需按真实调用/栈序理解；`0x2B000002` 类 token 是 MethodSpec（泛型实例化），可先用 `Module.ResolveMethod` 尝试。
7. **AutoUpdate 陷阱**：教师端登录后会启动 `TTLXAutoUpdate.exe` 重启自身为独立进程。替换为空壳会导致教师端退出；应保留原文件，让宿主在 `ExecuteAssembly` 返回后继续存活（静态字段值保留在宿主 AppDomain 内）。
8. **明文判定**：乱码 UTF8 解码可能碰巧出现汉字，判定要用"汉字 ≥10 且占比 ≥30%"避免误报。
9. **配置还原**：抓包时把教师端/学生端 config 的 `schoolip` 改成过 `127.0.0.1`，任务结束要改回 `10.5.17.90`（学生端 `TTStuentExam.exe.config` 也查）。
